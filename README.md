# Learn defensive security

Learn to describe a system, identify important assets and verify protective controls through small, repeatable exercises.

**Start here:** [Build a threat-and-control worksheet](guides/01-threat-and-control.md). No tools or administrator access required.

| Step | Topic | Status |
| --- | --- | --- |
| 1 | [Threats, controls and evidence](guides/01-threat-and-control.md) | Concept exercise available |
| 2 | Account and access review in a disposable lab | Planned |
| 3 | Host hardening with a tested recovery path | Planned |
| 4 | Logs, backups and recovery drills | Planned |

These are educational examples, not a certification or an assurance that a system is secure. Hands-on exercises must stay within systems you own or are authorized to administer.
