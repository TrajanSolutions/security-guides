# Contributing

Use Issues for topic proposals, questions and reproducible corrections. Explain the learner's goal, the affected guide, expected behavior and what you observed. Never include credentials or private information.

For a tutorial, copy templates/tutorial.md, keep the scope small, cite original documentation and submit a pull request. Include test evidence for runnable instructions; mark work that has not been executed as draft. Concept exercises should clearly state that no execution is claimed.

Be respectful, explain technical disagreements with evidence and avoid personal attacks. Maintainers review submissions; no response-time commitment is implied.

Before publication, follow the [shared publishing checklist](https://github.com/TrajanSolutions/.github/blob/main/PUBLISHING.md). Repository-wide licensing is not yet selected; discuss substantial external contributions with a maintainer before submitting them.
