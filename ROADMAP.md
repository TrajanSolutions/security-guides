# Security learning roadmap

## Available

Threat-and-control worksheet and tutorial templates.

## Planned labs

- Review accounts and permissions using fictional users in a disposable environment.
- Evaluate host configuration and record evidence before changing it.
- Practice a narrowly scoped firewall or authentication change with verified recovery access.
- Turn sanitized logs into a basic detection exercise.
- Restore sample data and document recovery evidence.

## Publishing criteria

Identify supported platform/version, scope, exact expected behavior, test evidence, potential lockout conditions and recovery steps. Use synthetic identities and data. Clearly distinguish draft recommendations from demonstrated results.
